# Strength Wave

A five-day strength log for one lifter. Home-screen web app for iPhone; no App Store, no account, no server. All data stays on the phone.

## Install on the iPhone

1. Open https://jnflmng-123.github.io/strength-wave/ in Safari.
2. Tap the Share button, then **Add to Home Screen**, then **Add**.
3. Open it from the home screen from now on. The home-screen copy keeps its own data, separate from the Safari tab, so install first and log second.

The app works offline after the first load. Updates arrive on the next open while online; the Data tab has a reload button if one seems stuck.

## What it does

- **Today.** Energy slider, body weight and a note, plus the day's session with each exercise's prescription for the current week of the wave. Tap an exercise, save sets with load, reps and RPE. Saving a set starts the rest timer. Main lifts fill the 90% back-off load from the top set and suggest a top set from the last one logged.
- **History.** Body weight with a 7-day average, energy, a per-lift chart of top sets and estimated max, and every session, editable.
- **Peptides.** Log doses. Compounds carry a default dose, shot days and a time; Today shows a banner when one is due. iOS does not let a web app schedule its own notifications, so the "Add reminders to Calendar" button builds a repeating Calendar event with an alert instead.
- **Program.** The wave (week 1 to 4) and the whole program, editable: swap, add, reorder, remove exercises; change sets, reps, RPE and percentages. Starting a new wave proposes week-1 top sets from what was logged.
- **Data.** Export to a JSON file through the share sheet (save it to OneDrive so the PC can read it), import from a file, rest-timer lengths, erase.

## Files

| file | job |
|---|---|
| `index.html` | shell, meta tags for iOS, font links |
| `app.js` | everything: store, program logic, rendering, actions |
| `styles.css` | layout and theme, light and dark |
| `sw.js` | service worker: app shell offline, fonts cached once seen |
| `manifest.webmanifest` | name, icons, standalone display |
| `icons/` | generated by a small Pillow script, oxblood square with a white barbell |

Deploying a change: bump `APP_VERSION` in `app.js` and `VERSION` in `sw.js`, commit, push. GitHub Pages serves `main` from the root.
